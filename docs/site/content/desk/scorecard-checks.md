# Scorecard checks

This is every check the [Scorecard](/desk/scorecard/) runs, grouped by area. It is generated from the check definitions in the source by `go run ./scripts/scorecard-checks`, so rerun that after changing a check.

There are 129 checks in every build. The five marked "(Enterprise, Agent reach)" only run when the `reach` feature of [Flightbay Enterprise](/enterprise/) is on, which makes 134.

| Area | Checks |
|---|---|
| Agentic | 58 (53, plus 5 with Agent reach) |
| Istio | 36 |
| Ingress | 11 |
| Kubernetes | 29 |

In the desk, filter the Scorecard with `id:` to find one check, for example `id:agentic.mcp-auth-required`. Each check in the desk has the explanation, the objects it looked at, the fix YAML, a link to a related field guide and upstream product documentation.

Severity weights: critical 10, high 6, medium 3, low 1. See [how the score works](/desk/scorecard/).
